A pasta `v001` contém a primeira entrega e `v002` contém a revisão baseada nas capas de `assets`. Para a próxima revisão, crie `v003`, preserve os arquivos anteriores e acrescente uma linha nesta tabela. O Git pode acompanhar cada revisão; nenhum commit é feito automaticamente.

Cada versão guarda o modelo, atlas, imagens, coordenadas dos pivôs, relatório de validação, fontes de geração e uma cópia das referências usadas. Isso permite reproduzir a entrega mesmo se a ficha original mudar.

O conteúdo desta pasta não é carregado pelo projeto Rojo. A substituição do Barão no jogo depende da importação e da integração posteriores.

Veja a entrega atual em [v002/README.md](v002/README.md) e o histórico em [v001/README.md](v001/README.md).
